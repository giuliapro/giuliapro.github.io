Description

Swapify is an application designed to map and promote swap party events, local markets where people can exchange items without the use of any currency. The app helps users easily find swap events in their area, offering a platform to share resources, improve consumer awareness and promote a more sustainable lifestyle.

My role in the project

The idea of Swapify was born for a university project, where I collaborated with three other teammates to design the app’s interface and the main flow of user experience. During this phase, we created a complete design system, developed layouts, mock-ups and prototypes, and conducted questionnaires and three full cycles of user tests to ensure an intuitive and functional user interface.

Additional work: Web application

After that, I continued the project on my own, turning Swapify into a full web application. I adapted the design for desktop view and then I started programming. I took care of both the front-end, using React to create a reactive and dynamic interface, and the back-end, implementing the logic and data management with Node.js and MongoDB. This allowed me to offer a smooth user experience and effectively manage information about swap party events.
